A variable-tempo metronome for Max.

This is a Max external, originally written against version 6.1.4 of the Max SDK and tested against Max 7. It now builds with the current [Max SDK](https://github.com/Cycling74/max-sdk-base) as a universal binary (Apple Silicon and Intel) and has been tested in Max 9. It reads breakpoint text files generated by [breakgen](http://github.com/flats/breakgen-Max) which modulate a given tempo by a given multiple on each beat and then sends a metronome output to the [player~](https://github.com/ericlyon/LyonPotpourri-MaxMSP/tree/master/LyonPotpourri2.0/Code/LyonPotpourri%20MSP%20Code/Xcode/player~) object. It's adapted from Eric Lyon's [samm~](https://github.com/ericlyon/LyonPotpourri-MaxMSP/tree/master/LyonPotpourri2.0/Code/LyonPotpourri%20MSP%20Code/Xcode/samm~) (Sample-Accurate Metronome Machine), which is a part of his incredible [LyonPotpourri libraries](https://github.com/ericlyon/LyonPotpourri-MaxMSP).

This patch has only been tested on macOS and may not work on other platforms (especially the parts related to file handling).

## Why This Exists

This exists because I wanted to create variable tempo maps (unsteady tempos, accelerando, rallentando, etc.) in Logic Pro X and Pro Tools. I generate a breakpoint file with breakgen, import that file with this object, wire the output up to player~, record the audio output, import the audio into one of those DAWs, and then detect the tempo.

## Installation

Download `OSX-modmetro~.zip` from the [latest release](https://github.com/flats/modmetro-Max/releases/latest) and drop the contents (`modmetro~.mxo` and `modmetro~.maxhelp`) into your Max user library. For Max 9 on macOS, that's `~/Documents/Max 9/Library/`.

The external is ad-hoc signed rather than signed with an Apple Developer ID, so macOS may block it after you download it. If Max says it can't load `modmetro~`, remove the quarantine flag:

```
xattr -dr com.apple.quarantine ~/Documents/Max\ 9/Library/modmetro~.mxo
```

## Building

You'll need Xcode (or the Command Line Tools) and [CMake](https://cmake.org) 3.19 or later. The Max SDK headers come in as a git submodule:

```
git clone --recursive https://github.com/flats/modmetro-Max.git
cd modmetro-Max
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

If you already cloned without `--recursive`, run `git submodule update --init` first. The universal `modmetro~.mxo` ends up in `externals/`. To work in Xcode instead, generate a project with `cmake -S . -B build -G Xcode` and open `build/modmetro-Max.xcodeproj`.
